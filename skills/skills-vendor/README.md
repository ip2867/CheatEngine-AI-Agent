## What is and is not included

The upstream repository is an index. Its skill bodies route to a sibling
`archive/` directory holding **18.61 GB** of third-party repository snapshots —
2666 author directories. That directory is **not** vendored here and is not
needed to use the skills as a classification and methodology reference.

Consequence: the `references/*.md` files that remain are self-contained routing
and judgement guides. Paths that pointed into `archive/` are dead in this copy.
Cite these skills for **how to think about a problem class**, not for a working
implementation of it.

## Not an endorsement

Upstream's own `AGENTS.md` states it plainly:

> Collection membership is not an endorsement or proof of capability.

A project appearing in that index does not establish that it works, that it
works on your version, or that the mechanism it describes is real. Verify
before you rely on anything it points at.

## Relation to the two first-party skills

`../game-memory-hunting/SKILL.md` and `../game-vision/SKILL.md` are written from
this project's own failed attempts on `gtutorial-x86_64.exe`. Where the two
disagree, the first-party skills win for this CE version and this machine —
they are field notes, these are maps.
